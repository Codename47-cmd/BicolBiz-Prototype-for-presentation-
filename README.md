# BicolBiz

📍 A community-based local business and services directory prototype for a BSCS capstone presentation.

Discover local businesses across the Bicol region through a clean, searchable directory.

🔗 **Live Demo → https://bicolbiz.netlify.app/**

## ✨ Features

- 🔎 Search and filter local business listings
- 🏪 Business detail pages with contact information
- ❤️ Save favorite businesses using browser storage
- 🗺️ Mock regional map for exploring listings
- 📊 Simple admin dashboard overview
- 📱 Responsive design for desktop and mobile

## 🚀 How to Use

1. Visit the [live demo](https://bicolbiz.netlify.app/) or run the project locally.
2. Browse businesses from the home page or Explore page.
3. Use search and category filters to find listings.
4. Save businesses to view them later in Favorites.

## 💻 Run Locally

```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, Tailwind CSS, and React Router.

> This is a front-end prototype using sample data and browser local storage. It does not have a backend or live map API.
